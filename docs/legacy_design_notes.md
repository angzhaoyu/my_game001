# 一、土地属性表 Soil_Data

每块土地都有独立属性。

| 属性             | 范围        |
| ---------------- | ----------- |
| 土地ID           | 1-24        |
| 氮 N             | 0-100       |
| 磷 P             | 0-100       |
| 钾 K             | 0-100       |
| 湿度 Moisture    | 0-100       |
| 温度 Temperature | -10~45℃    |
| 当前作物         | NULL/作物ID |
| 作物阶段         | 1-3         |
| 害虫等级         | 0-100       |
| 病害等级         | 0-100       |

肥力过高惩罚   最高惩罚为成长速度80% 。

# 八、最终每日成长公式（核心）

作物的 每日成长 = 基础成长速度 × 温度倍率 × 湿度倍率 × 肥力倍率× 病虫倍率
